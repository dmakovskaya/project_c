# Алгоритмы кластеризации

Проект представляет собой реализацию алгоритма кластеризации K-means на языке C для сегментации клиентов. Программа анализирует данные о транзакциях (RFM-показатели: Recency, Frequency, Monetary, Variety) и делит клиентов на группы (VIP, постоянные, спящие).

## Основные возможности
- **Масштабируемость:** Реализована эффективная работа с динамической памятью.
- **Предобработка:** Включает логарифмическое преобразование `log1p` для нормализации данных и стандартизацию признаков.
- **Метод локтя (Elbow Method):** Программа автоматически помогает определить оптимальное количество кластеров (K).
- **Интерактивность:** Возможность классифицировать нового клиента в режиме реального времени после обучения модели.

## Структура проекта
- `main.c` — логика программы, генерация данных и управление процессом обучения.
- `kmeans.c` — ядро алгоритма K-means (расстояние, назначение точек, обновление центроидов).
- `kmeans.h` — описание интерфейсов и структур данных.
- `test_runner.c` — набор тестов для проверки математических функций.

## Сборка и запуск

### Компиляция
Для компиляции проекта используйте GCC:
```bash
gcc main.c kmeans.c -o rfm_analysis
```

Для запуска выполните команду:
```bash
./rfm_analysis
```
