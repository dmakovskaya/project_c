# Алгоритмы кластеризации

Данный проект представляет собой программный комплекс для сегментации клиентской базы, базирующийся на оптимизированном алгоритме K-means++. Реализация включает в себя полный цикл обработки данных: от статистической стандартизации до кластеризации по пяти RFM-признакам. В проект внедрены инструменты аналитической верификации: метод локтя для подбора гиперпараметров, расчет метрик точности и детектор аномалий, позволяющий выявлять нетипичное поведение клиентов.

## Основные возможности
- **RFM-анализ с 5 признаками:** Реализована модель, учитывающая Давность (Recency), Частоту (Frequency), Выручку (Monetary), Разнообразие (Variety) и Средний чек (Average Order Value).
- **Предобработка данных:** Включает логарифмическое преобразование `log1p` для нормализации данных и стандартизацию признаков.
- **Метод локтя (Elbow Method):** Программа автоматически помогает определить оптимальное количество кластеров (K).
- **Интерактивность:** Возможность классифицировать нового клиента в режиме реального времени после обучения модели.
- **Оптимизация и сходимость:** Алгоритм автоматически останавливается при достижении порога tol (минимального смещения центроидов).
- **Инициализация k - means++ :** Улучшенный выбор начальных центроидов для более стабильной и быстрой сходимости алгоритма.
- **Детекция аномалий :** Автоматическое выявление клиентов-выбросов на основе расстояния до ближайшего центроида.
- **Оценка точности :**  Расчёт процента правильного сопоставления кластеров с истинными метками (при наличии ground truth).


## Структура проекта
- `main.c` — логика программы, генерация данных и управление процессом обучения.
- `kmeans.c` — ядро алгоритмов: K-means (расстояние); k-means++ (назначение точек, обновление центроидов).
- `kmeans.h` — описание интерфейсов и структур данных.
- `anomalies.c` — детекция выбросов и расчет метрик качества.
- `anomalies.h` — интерфейс модуля аномалий.
- `tests.c` — набор тестов для проверки математических функций.

## Сборка и запуск

### Компиляция
Для компиляции проекта используйте GCC:
```bash
gcc -O2 -Wall -Wextra -o rfm_analysis main.c kmeans.c anomalies.c -lm
```

Для запуска выполните команду:
```bash
./rfm_analysis
```
